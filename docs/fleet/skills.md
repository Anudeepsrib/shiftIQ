# Skills

Nine Agent Skills live in `fleet/skills/`: assessment, planning, safe dry run, secure apply, verification, rollback, compliance review, GitHub workflow, and executive reporting. Each `SKILL.md` has a selective discovery description and only task-specific procedure.

In Fleet, add these under Knowledge > Skills. Keep them private while testing; publish stable skills to the workspace when multiple agents should reuse them. Shared skill ownership and editing remain Fleet-managed.
